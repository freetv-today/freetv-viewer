# FreeTV Viewer Version 4.0 (Dev)

This is the next generation of the FreeTV Viewer (frontend) site. 

It is a fresh start and is not attached to any previous code from versions 1 - 3.

The goal is extreme simplification. Nothing is added that doesn't need to be there.

This version will incorporate the new dev player using HTML5 video and not use iframes from the Internet Archive.

Development started on 9/24/26

There is no deadline or target date. It gets released when it's done.
